# solidcraft (Vibeclones mirror)

Hosted copies of older browser (WebAssembly) builds of [solidcraft](https://github.com/tangency-labs/solidcraft), a parametric 3D CAD app by Tangency Labs. The author's own site, [solidcraft.io](https://solidcraft.io), serves only the newest version; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/solidcraft/latest/`
- Specific version: `/solidcraft/v<version>/`
- Version list: `/solidcraft/versions.json`

Each version folder is the unmodified contents of upstream's `solidcraft-web-<version>.zip` release asset, including its license files. Upstream license: Apache-2.0. A scheduled workflow mirrors new releases.
